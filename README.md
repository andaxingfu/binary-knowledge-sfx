# 二进制 · 惊异之学

> **BGM 说明：** 背景节奏为 **Web Audio API 程序合成**（约 113 BPM、16 拍 ≈ 8.5s 循环、F 持续低音、稀疏 Eb/F/Fm 和弦垫），灵感来自对「上头 BGM」类知识片节奏公式的拆解笔记，**不是**抖音原曲 stem / 版权音轨投放。`audio/bgm.mp3` 可留在磁盘作对照，默认关闭（`USE_MP3_BGM = false`）。

单文件夹自包含 H5 知识讲解片（约 3 分 40 秒）。五幕结构 + 开场钩子回调；**旁白已关闭**，仅保留轻 SFX 与程序化 Web Audio BGM（`audio/n*.mp3` 仍在磁盘，默认不加载）。

## 打开

```bash
cd /workspace/binary-knowledge
python3 -m http.server 8766
```

浏览器打开：http://127.0.0.1:8766/

封面轻触开始（用户手势解锁音频）。空格暂停/继续，←/→ 快退/快进 5 秒，R 重播。调试：`?t=秒`。

## 五幕大纲

0. **序 / Hook** — 「亮。」→ 空白「下一秒呢？」→「灭。」你已经猜到了；引出只有两种可能。
1. **基本单元** — 一盏灯 = 一个比特；可点按 0/1 开关；八比特成字节。
2. **核心理论** — 权位 2ⁿ；解码 1011₂ = 11₁₀；莱布尼茨。
3. **摩擦** — 误解「只属于计算机」；噪声翻转比特；冗余与纠错。
4. **宏大尺度** — 2¹⁰ / 2³⁰；旅行者金唱片；DNA 两位一码。
5. **余响** — 世界可被问成是与否；回调「亮。」与空白：「这一次，由你来填。」

## 音频说明

- **旁白关闭：** `ENABLE_NARRATION = false`；不加载/播放 `audio/n*.mp3`，也不走 Web Speech。需要旁白时改回 `true`。
- 环境床音：默认程序化 Web Audio（113 BPM / F 踏板 / Eb·F·Fm·Fm；封面点击后解锁；音量约 0.14）。可选 `USE_MP3_BGM` 回退到 `audio/bgm.mp3`（仅调试）。
- 轻 SFX：打字、软击、低音等仍由 Web Audio 触发。
- 浏览器通常要求先有用户手势才能出声；请从封面点击开始，不要静默自动播放。
